DADS PowerPoint Skill 作業ログ
作成日: 2026-09-27

■ ご依頼の流れ

1. DADS（デジタル庁デザインシステム HTML版）の全コンポーネントを網羅した、
   固定のPowerPoint仕様カタログを作成したい。

2. DADSデザインシステムを使ってPowerPointスライドを作成するための
   Agent Skill（SKILL.md）を作成したい。

3. Skillにローカル固有のパスを使わず、テンプレートもSkillに同梱したい。

4. スライドやコンポーネントの出力例もテンプレート／Skill配布物に含めたい。

5. GitHubリポジトリ https://github.com/atchyxx/design_system に公開し、
   ZIP形式でダウンロードできるようにしたい。

■ 実施内容

1. 全コンポーネントの仕様カタログを作成
   - 対象: 42コンポーネント
   - ファイル: dads-component-spec-catalog.pptx
   - スライド数: 46
   - 各コンポーネントの仕様、状態、アクセシビリティ要件を整理。

2. Storybook実表示を使った完全ビジュアルカタログを作成
   - 対象: 42コンポーネント、129 Storybookストーリー
   - ファイル: dads-complete-visual-catalog.pptx
   - スライド数: 132
   - デスクトップ幅（1440px）とモバイル幅（390px）の実表示を収録。
   - hover、focus、キーボード操作、アニメーション自体はPowerPoint内では実行せず、
     静的な見本として収録。

3. DADS PowerPointテンプレートを作成
   - ファイル: dads-powerpoint-template.pptx
   - 編集可能な6種類のレイアウトを収録。
     1) 表紙
     2) セクション区切り
     3) 本文と図表の2カラム
     4) 3カード比較
     5) 4ステッププロセス
     6) クロージング／次のアクション

4. Agent Skillを整備
   - Skillパス: .agents/skills/create-powerpoint/
   - 本体: .agents/skills/create-powerpoint/SKILL.md
   - Agent SkillsのSKILL.md形式（YAML frontmatter）に対応。
   - Skill名: create-powerpoint
   - DADSトークン、コンポーネント、Storybook、テンプレートを参照して
     PowerPointを作るための手順を記載。
   - ユーザー固有のローカルパスへの依存を除去。
   - skills-ref validate により、有効なSkillであることを確認済み。

5. 再生成スクリプトを追加
   - .agents/skills/create-powerpoint/scripts/generate-dads-powerpoint-template.cjs
   - テンプレートPPTXを再生成するNode.jsスクリプト。

■ 軽量化ブランチでの追加作業

容量制限への対応として、mainを変更せず、次のブランチでSkillを再構成した。

  feat/lightweight-powerpoint-skill

初期の軽量化では、重いPPTXカタログをSkill本体から除外し、テキスト抽出したMarkdown参照資料とデザインスタイル手順書へ置き換えた。

- PowerPointの編集可能テンプレート、固定仕様カタログ、完全ビジュアルカタログのPPTX本体をSkillパッケージから除外。
- PPTXのテキストはUTF-8で抽出してMarkdown化。
- DADSの色、書体、余白、6レイアウト、情報階層、図表、UI見本、アクセシビリティ、品質確認を
  dads-design-style.mdへ明文化。
- PPTXをMarkdownへ再抽出するextract-pptx-text.pyを追加。

その後、利用時に外部参照なしで仕様を読めるようにする方針へ変更した。

- SKILL.mdへDADSの全プリミティブ／ニュートラルカラー144件と、セマンティックカラー8件を追加。
- リポジトリ実装を根拠に、モバイルファースト、768pxブレークポイント、hover環境、
  強制カラーモード、視覚効果低減、状態の静的表現、Button／Inputの値を追加。
- 全42コンポーネントについて、HTML例、Storybook、公開data-*バリエーション、状態、
  メディアクエリ、アクセシビリティシグナル、PowerPoint化チェックリストを生成する
  dads-component-inventory.mdとgenerate-component-inventory.cjsを追加。
- ユーザー指定により、全42コンポーネントの個別CSS値・全バリエーション・全状態を
  SKILL.md本文の固定コンポーネント仕様スナップショットとして埋め込んだ。
- Foundation CSS全文（タイポグラフィ、エレベーション、フォーカス、リンク、強制カラー、
  視覚効果低減）、コンポーネント動作ソース13件、アセット30件の一覧と利用規則も
  SKILL.md本文へ追加。
- 固定スナップショットは、generate-component-inventory.cjsと
  embed-component-specifications.cjsで再生成できる。

■ 直近の確認依頼

「このスライドは、デジタル庁のデザインスタイルの通りに作成できていますか？」という
確認依頼があった。

評価対象のPowerPointファイルまたは対象スライドの画像が添付されていなかったため、
DADSの色、書体、余白、情報階層、アクセシビリティ、コンポーネント再現の観点での
判定は実施していない。

評価を行う場合は、対象の .pptx ファイルまたは対象スライドのスクリーンショットを
確認対象として提供する必要がある。
